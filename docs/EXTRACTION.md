# Выделение CSSE из исходного архива (история первого этапа)

Дата подготовки: 19 октября 2026.
Входные файлы: `MWSE-master (1).zip` и `MWSE-инструкции.zip`.

## Что сохранено

- Все 82 исходника `.cpp` проекта CSSE и его заголовки/ресурсы.
- Все 78 исходников `.cpp`, включённых исходным `SharedSE.vcxitems`.
- Остальные общие заголовки, включая неактивные конфигурации другой цели,
  чтобы не проводить ненужную переработку общей реализации.
- Заголовки fmt, toml11 и DirectX 8 из архива.
- 27 PNG-ресурсов значков тёмной темы.
- Оригинальный текст GPL v2 и имеющиеся уведомления сторонних компонентов.

## Что отделено и изменено

- `CSSE.sln` содержит один DLL-проект CSSE. `SharedSE.vcxitems` включён
  внутрь проекта и не образует отдельную библиотеку.
- Удалена зависимость сборочных настроек от `MWSE.sln`, `MWSE.props`,
  `MorrowindDir`, AppVeyor и соседних MWSE-проектов.
- Исключены MWSE, updater, документация Lua API, игровые Lua-скрипты,
  Boost, sol, LuaJIT/rubic0n, lpeg, yaml-cpp и NuGet-пакеты.
- `config/CSSE.props` и `.targets` задают общий PCH, C++20, UTF-8,
  статические MFC/CRT и независимые каталоги результатов.
- `BuildDate.h` создаётся средствами MSBuild в промежуточном каталоге,
  не изменяя исходники во время сборки.
- Номер сборки передаётся как `CSSE_BUILD_NUMBER`; в GitHub используется
  номер запуска workflow. Для локальной сборки по умолчанию используется 0.
- Обновлены три места вывода номера сборки: CSSE.cpp,
  CrashLoggerCSSE.cpp, DialogAboutCSSE.cpp.
- Два используемых пути `Data Files/MWSE/...` перенесены в
  `Data Files/CSSE/...`: значки и временный профиль OpenMW.
- Постсборочная установка DLL/PDB разрешается только явной настройкой
  в локальном `CSSE.User.props` или соответствующих свойствах MSBuild.
- Добавлены сборка Debug/Release в GitHub Actions, ZIP-пакеты, отдельные
  символы, SHA-256 и проверки структуры проекта/архитектуры/импортов DLL.

## Уточнения к приложенным инструкциям

В инструкции описана локальная вставка `showStartupTestWindow()` с окном
«Удачный тест». В **CSSE.cpp фактически присланного архива** такой функции
и вызова нет. При выделении проекта она не добавлялась; исходное поведение
инициализации сохранено.

Сборка CSSE не требует `deps/rubic0n`, yaml-cpp или .NET Framework:
упомянутые в инструкции операции относятся к сборке всего решения MWSE.

Для загрузки CSSE.dll в оригинальный редактор сохранён исходный механизм
через MGE XE. Новый загрузчик не создавался. Полноценное внедрение
тестового окружения в Morrowind остаётся дополнительной внешней
интеграцией с MWSE; её игровые Lua-скрипты здесь не поставляются.

## Проверка

Статическая проверка комплектности, XML, списка исходников и ресурсов
выполнена в Linux. Отдельно проверены активные локальные include-зависимости
для цели Construction Set и сохранение исходных кодировок/концов файлов.
Полная компиляция MSVC/MFC и запуск в TES Construction Set в этой среде
недоступны. Workflow для этих сборок подготовлен, но до загрузки
репозитория его успешное выполнение не заявляется.
